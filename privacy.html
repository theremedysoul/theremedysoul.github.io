개인정보처리방침

최종 수정: 2026년 9월 28일

YouTube AI Inbox는 소유자 한 명의 개인용 자동화 도구입니다. 이 안내 페이지는 공개되지만, 사용자의 영상 목록이나 생성 문서는 이 사이트에 게시하지 않습니다.

접근하는 정보와 목적

앱은 사용자가 승인한 YouTube 읽기 전용 권한으로 소유한 재생목록, 항목, 영상 제목·채널·길이 등의 정보를 읽습니다. 승인한 Google Drive 파일 권한으로 앱이 사용하는 폴더, 요약 문서, 월별 읽기 목록, 처리 관리표를 만들고 갱신합니다. 이 정보는 새 영상 발견, 중복 처리 방지, 요약 생성과 실행 상태 확인에만 사용합니다.

사용자가 이메일 알림을 켜면 앱은 Gmail 발송 전용 권한으로 지정한 수신 주소에 새 요약의 제목, 짧은 요약, 문서·원본 영상 링크를 보냅니다. 받은편지함이나 기존 메일은 읽지 않습니다. 메일 본문과 수신 주소는 Gmail 서비스의 처리 대상이 됩니다.

외부 서비스와 저장 위치

공개 영상의 URL, 영상 길이, 분석용 지시문은 요약을 위해 Google Gemini API로 전송됩니다. 비공개 재생목록의 이름과 항목 목록은 Gemini 요청에 포함하지 않습니다. 무료 Gemini API에서는 Google이 전송된 내용과 응답을 제품 개선에 사용할 수 있습니다. Gemini API 약관을 참고하세요.

OAuth 토큰은 소유자의 로컬 컴퓨터와 비공개 GitHub Actions Secrets에 저장됩니다. 선택한 재생목록의 이름과 ID, 앱 설정은 비공개 GitHub 저장소에 보관됩니다. 요약과 처리 기록은 소유자의 Google Drive, Docs, Sheets에 저장됩니다. 이 앱은 데이터를 판매하거나 광고 목적으로 사용하지 않습니다.

보관 및 삭제

앱은 자동 보관 기간을 설정하지 않습니다. 소유자가 Google Drive의 앱 폴더와 관리표를 삭제할 때까지 생성 자료가 남을 수 있습니다. Google 계정의 제삼자 앱 연결 관리에서 접근 권한을 철회할 수 있습니다. 로컬 토큰 파일과 GitHub Actions Secrets도 소유자가 삭제할 수 있습니다. 권한 철회만으로 이미 만들어진 Google 문서가 자동 삭제되지는 않습니다.
